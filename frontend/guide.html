A current guide to setting up plate geometry, refining densitograms, calibrating results and producing reports in the three-panel desktop workspace.

Start-to-finish workflow

Load the plate imageDrop an image anywhere on the upload screen, or click Browse to select it. The longest image dimension is reduced to 1000 px for analysis.
Prepare the plateCrop away unused background and rotate the plate so the sample lanes run vertically. Do this before adding lines and marks.
Draw the boundariesSelect Boundary Lines and drag one line across the origin and another across the solvent front. The origin must be below the front, and the lines must be vertically separated.
Add sample positionsSelect Spotting Marks and click once at each application position along the origin. Marks placed near the origin snap onto it.
Find and inspect lanesClick Find Lanes. Blue lane boxes appear and the first lane opens in the analysis panel. Check the geometry and adjust any lane before accepting its profile.
Quantify and reportRefine peaks, choose Relative Intensity, Area Calibration or MW Calibration, enter standards where needed, then export the active lane or a full multi-lane report.
Session warning: the Desktop workspace is temporary. Export required reports before refreshing, closing the tab or allowing the Streamlit session to restart. The app does not currently save a project file for later reopening.

Left panel and canvas tools

Crop ROI

Drag a rectangle around the region to keep. The crop is applied when the mouse is released and rotation is baked into the cropped image.

Pan & Zoom

Drag empty canvas space to pan. Use the mouse wheel to zoom around the pointer position.

Rotate

Drag horizontally for fine rotation. Double-click the image to rotate exactly 90° clockwise.

Select & Edit

Click and drag a line, spotting mark or lane to move it. Select an item and press Delete or Backspace to remove it.

Boundary Lines

Drag to create a line. Drag an existing line to move it, or drag near an end to resize it.

Spotting Marks

Click once per sample lane at the origin. Each mark produces one calculated lane.

To reverse a recent geometry or image edit, press Ctrl + Z on Windows or ⌘ + Z on macOS. The in-session undo stack holds up to 50 snapshots.

Image and signal controls

  • RGB Channel Projection offers Full RGB, named visual presets and a custom target from 380 to 750 nm. The RGB window control averages the approximate channel weights at each integer nm from target minus window to target plus window (0–50 nm), clipped to the supported range. A zero window keeps the existing single-target weighting; Full RGB ignores the window.
  • Invert reverses image colours and updates the analysed profiles.
  • Changing projection, RGB window or Invert recalculates profiles and runs automatic peak detection again. Manual peak edits are replaced, so finish your filter choice before editing peaks.
  • Polarity Mode selects Default, Dark Spots or Bright Spots to match the plate appearance.
  • Sens. controls how readily weaker peaks are detected; Res. controls minimum peak separation; Width % controls the threshold used to define each peak's visible and analytical integration boundaries.
RGB projection is image processing, not spectroscopy. Named wavelength and staining presets, including the RGB window, combine channels already present in the camera photo. They do not represent a physical optical filter, monochromator or measured spectral bandwidth.

New versus Reset

  • New clears the current analysis and returns immediately to the upload screen.
  • Reset keeps the uploaded image but restores its original uncropped, unrotated state; it also clears lines, marks, lanes and RGB/invert adjustments.

Right panel: select a lane and refine peaks

Use the Select tool and click a blue lane box to make it active. The right panel shows its editable name, densitogram, result table and report controls.

Densitogram interactions

  • Add a peak: single-click empty chart space inside the valid Rf range.
  • Move a peak: drag its apex marker left or right.
  • Resize the measured interval: drag either vertical boundary handle. The cursor changes to a horizontal resize indicator near a boundary.
  • Delete one peak: right-click its apex marker.
  • Run detection again: double-click the chart or choose Reset integration. This can replace manual edits with a new automatic result.
  • Navigate: use the mouse wheel to zoom horizontally around the pointer. Choose Reset view to show the full profile.
  • Clear the lane: choose Delete all peaks to remove every peak from the active lane.
Gold — automatically detected peak.
Red with an asterisk — manually added or adjusted peak.
Green — a peak assigned as a calibration standard.
How area is measured: peak area is the baseline-corrected trapezoidal area of the normalized analytical profile between the single pair of Width-controlled boundary edges. Dragging either edge immediately recalculates the area.

Choose an integration mode

Relative Intensity

Calculates each peak as a percentage of total integrated area within its lane. Abs Ratio is an optional response correction: corrected area is area divided by the ratio. Leave it at 1 for no correction.

Area Calibration

Set known peaks to S and enter their values; set unknowns to A; use N to exclude a peak. One standard gives a line through zero, while two or more valid standards use linear regression.

MW Calibration

Set at least two peaks with known positive molecular weights to S, then set unknowns to A. The app interpolates or extrapolates piecewise in log10(MW) versus Rf space.

Standards are collected from every lane in the current image, so assignments in one lane can affect analyte values elsewhere. Check that standards use consistent units and distinct valid values.

Export reports

  • Export Lane prepares a report for the active lane.
  • Full Report prepares a multi-page report for all lanes.
  • The report includes the lane image, densitogram and table for the currently selected integration mode. In the browser print window choose Print or Save as PDF. If the report window is blocked, a printable HTML file is downloaded instead.

For more reliable results

  • Capture the plate square-on with even illumination and minimal glare or shadow.
  • Place origin and solvent-front lines at the true physical boundaries and keep them parallel.
  • Use compact, well-separated sample spots and avoid overloaded or streaked lanes.
  • Inspect every lane box, profile, integration boundary and standard assignment before reporting.
  • Treat AQ-TLC as an analytical aid. Validate image capture, peak detection and calibration for the intended plate chemistry and laboratory method.
Data handling: the plate image is sent to the selected Streamlit app for analysis. Do not upload sensitive material until the deployment's access controls and your organisation's privacy requirements have been confirmed.
