AQ-TLC Desktop v1.0 for Windows (64-bit)

1. Extract the whole ZIP before running the app.
2. Keep AQ-TLC-Desktop.exe and the _internal folder together.
3. Double-click AQ-TLC-Desktop.exe. The app opens in your default browser.
4. Close the executable's console window when you are finished.

The app runs locally on this computer. It does not need an internet connection
or a Python installation. Your working session is temporary; export reports
before closing the app. If the browser does not open, use the local address
printed in the console window.

This Windows package includes the AQ-TLC Desktop analysis backend and interface.
Third-party licenses are in _internal/licenses.
