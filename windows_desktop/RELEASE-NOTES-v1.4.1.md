# AQ-TLC Desktop v1.4.1 for Windows (64-bit)

This portable release brings the online Desktop boundary-line drawing fix to Windows.

- The Lines tool grabs an existing Origin or Front line only when the pointer starts within 8 visible pixels of it, at any zoom level. Starting farther away draws a new line.
- Moving an existing line and resizing it at an endpoint remain available.
- Shoulder analysis, the Default asymmetry option, Maximum peak asymmetry (R), and the Area Calibration behavior from v1.4 remain available.

Extract the entire `AQ-TLC-Desktop-v1.4.1-Windows-x64.zip` and run `AQ-TLC-Desktop.exe` with its `_internal` folder beside it. The app runs locally without Python or an internet connection. Export reports before closing the temporary analysis session.
